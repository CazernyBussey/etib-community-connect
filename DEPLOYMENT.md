# ETIB Community Connect deployment guide

## Render deployment

The repository includes a Render Blueprint in `render.yaml`. It pins Node.js 24, installs from the lockfile, starts the Express service, checks `/api/health`, and mounts a persistent disk at `/var/data`.

Required or sensitive environment values:

- `JWT_SECRET`: generated by the Blueprint; it must remain at least 32 characters in production.
- `ADMIN_EMAIL`: receives moderation messages and identifies the account created by the trusted admin-bootstrap command.
- `ADMIN_NAME` and `ADMIN_PHONE`: used when the trusted admin-bootstrap command creates a new administrator.
- `PUBLIC_BASE_URL`: the canonical public origin used to construct password reset links.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, and `SMTP_FROM`: required for password reset and moderation email delivery.
- `DB_PATH`: set to `/var/data/etib.db` so records survive deploys and restarts.

Do not commit live credentials or a production database.

## Administrator bootstrap

After the first deploy, open a trusted Render shell in the service and run:

```bash
npm run create-admin
```

The command creates or securely rotates the `ADMIN_EMAIL` account and prints a generated temporary password once. Sign in immediately, use password recovery to choose a private password, and clear the shell output. Public signup never grants administrator access.

## Release checks

Run these before deployment:

```bash
cd server
npm ci
npm test
npm audit --omit=dev
```

After deployment, verify:

1. `/api/health` returns `{"ok":true}`.
2. The directory, filters, pagination, featured cards, and business profiles load without console errors.
3. A new owner can sign up with a real phone number, sign in, submit a listing, and edit it from the owner dashboard.
4. An administrator can approve the user, moderate the listing and a review, and set or remove featured placement.
5. Approved content appears publicly; pending or rejected content does not.
6. A password reset message arrives, its link works once, and the new password signs in.
7. Keyboard-only navigation, zoom at 200%, forced-colors mode, and at least one current screen reader work across public, owner, and admin pages.

## Data durability

SQLite is stored on the attached Render disk. Keep regular backups of `/var/data/etib.db`, especially before schema or hosting changes. A managed Postgres migration is the appropriate next step if write volume or multi-instance scaling grows beyond a single service.
